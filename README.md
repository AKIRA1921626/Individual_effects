# Individual_effects
指定した文字たちに別々のアニメーションを付与するAviutl2のスクリプト。  
テキストオブジェクトで「文字ごとに個別オブジェクト」にcheckを入れた状態で使用すると、それぞれに違うアニメーションを付与することができます。  
「@個別エフェクト.anm2」でどの文字に度のエフェクトを追加するかを指定し、それでも足りない場合、「@個別エフェクト(エフェクト追加用).anm2」でエフェクトを追加します。  
「@個別エフェクト.anm2」だけでも使用することが可能ですが、「@個別エフェクト(エフェクト追加用).anm2」だけでは正常に動作しません。  
あまり動作は安定しないので、他のスクリプトと組み合わせると落ちることがあります。  
スクリプト一覧では「@個別エフェクト.anm2」は「個別エフェクト」というところに表示されるようになっています。  
スクリプト一覧では「@個別エフェクト(エフェクト追加用).anm2」は「個別エフェクト追加」というところに表示されるようになっています。  
**「@個別エフェクト.anm2」「AKIRA_aviutl2_helper.lua」「group_effect_common.lua」「@個別エフェクト(エフェクト追加用).anm2」「group_effect_add_effect_common.lua」の5つを同じファイルに入れてからご使用ください。**  
「個別エフェクト単品.anm2」は、AIに参考にしてもらうように見せたひな型となります。実用性はありません。  
また、標準スクリプトだけを使用しているものもありますが、一部のエフェクトは、「@各種登退場_AKIRA.anm2」「移動登場_AKIRA」という外部スクリプトを使用しているものも存在します。  
「@各種登退場_AKIRA」  
https://github.com/AKIRA1921626/Various-appearance-animations  
「移動登場_AKIRA」  
https://github.com/AKIRA1921626/moving-appearance  
これらは同じフォルダにある必要はなく、Aviutl2で使えるようになっていれば該当エフェクトで使用することが可能となります。  

二次配布可、改変可、クレジット不要
