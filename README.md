# Individual_effects
指定した文字たちに別々のアニメーションを付与するAviutl2のスクリプト。  
テキストオブジェクトで「文字ごとに個別オブジェクト」にcheckを入れた状態で使用すると、それぞれに違うアニメーションを付与することができます。  
あまり動作は安定しないので、他のスクリプトと組み合わせると落ちることがあります。  
スクリプト一覧では「個別エフェクト」というところに表示されるようになっています。  
「@個別エフェクト.anm2」「AKIRA_aviutl2_helper.lua」「group_effect_common.lua」の3つを同じファイルに入れてからご使用ください。  
また、標準スクリプトだけを使用しているものもありますが、一部のエフェクトは、「@各種登退場_AKIRA.anm2」「移動登場_AKIRA」という外部スクリプトを使用しているものも存在します。  
「@各種登退場_AKIRA」  
https://github.com/AKIRA1921626/Various-appearance-animations  
「移動登場_AKIRA」  
https://github.com/AKIRA1921626/moving-appearance  
これらは同じフォルダにある必要はなく、Aviutl2で使えるようになっていれば該当エフェクトで使用することが可能となります。  

二次配布可、改変可、クレジット不要
